# Maths Solution with Nick

Responsive static educational website built with HTML, CSS and vanilla JavaScript. No framework, build step, paid service or remote image dependency is required.

## Local preview
Open index.html in a browser. Keep the images/ directory beside it.

## GitHub Pages
A GitHub Actions workflow deploys the site from main. In repository Settings → Pages, select GitHub Actions as the deployment source if required.

## YouTube destination
The channel URL is configured in index.html as https://www.youtube.com/@MathsSolutionWithNick. Update it there if the handle changes.

## Content note
Learning areas and revision support are presented for educational purposes; the site does not claim accredited qualifications or institutional affiliation.
